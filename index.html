Notes and to-dos, one tab away in your shell.

Caelestia Notes is a lightweight, local-first productivity plugin for Caelestia Shell on Linux. It brings daily habit tracking, an animated clover date picker, and pinnable, zero-lag Markdown notes directly into your Material 3 desktop.

Get it on GitHub Explore Features

Smart to-dos with repeating daily habits

Write tasks, set dates with the rotating 4-leaf clover calendar picker, or toggle recurring daily habits. Habits automatically reset every midnight so you wake up to a fresh checklist, while completed habits and general tasks stay organized in split drawers.

Markdown engine with zero typing lag

Full support for headings, bold, italics, inline code, and blockquotes. Typing is decoupled from markdown parsing for instant keystroke response, while bullet lists cycle through Material 3 algorithmic Cookie, Sunny, and Clover shapes.
