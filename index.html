Notes and to-dos, one tab away in your shell.

Caelestia Notes is a lightweight, local-first productivity plugin for Caelestia Shell on Linux. It brings daily habit tracking, an animated clover date picker, and pinnable, zero-lag Markdown notes into your Material 3 desktop.

    Smart to-dos with repeating daily habits

    Write a task, pick a date with the animated 4-leaf clover picker, or mark it as a daily habit. Daily habits reset automatically at midnight so you start fresh every morning, while a split trash bin keeps completed habits and deleted tasks neatly separated.

      Markdown engine with zero typing lag

      Full support for headings, bold, italics, inline code, and blockquotes. Typing is completely decoupled from markdown evaluation for instantaneous key response, while lists feature morphing Material 3 algorithmic shapes that cycle with nesting depth.
