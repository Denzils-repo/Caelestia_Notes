        Smart to-dos with repeating daily habits

        Write a task, pick a date with the animated 4-leaf clover picker, or toggle it as a daily habit. Daily habits automatically reset at midnight so you stay consistent every morning. Completed habits and deleted tasks stay separated in a dedicated recycling drawer.

          Markdown engine with zero typing lag

          Full support for headings, bold, italics, inline code, and blockquotes. Typing is decoupled from markdown evaluation for instantaneous key response, while lists feature morphing Material 3 algorithmic shapes that cycle with nesting depth.
